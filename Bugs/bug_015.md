# Bug 015: карточка товара ограничена одним изображением

## Статус
`Open`

## Приоритет
`Major`

## Окружение
- Платформа/ОС: Windows 10
- Браузер (если применимо): Google Chrome

## Описание
В карточке любого товара добавлена лишь одна картинка, что делает их не информативными. Особенно это проблема для мерча и посуды. Это может привести к вовратам товаров.

## Шаги для воспроизведения
1. Зайти на сайт и авторизоваться.
3. Открыть каталог.
4. Открыть товар из каталога.
5. Убедиться, что картинка в карточке товара всего одна.


## Фактический результат
В карточках товаров размещена лишь одна картинка.

## Ожидаемый результат
В карточках товара несколько картинок (особенно в карточках с мерчом и посудой, где хочется рассмотреть подобнее мелкие детали).
